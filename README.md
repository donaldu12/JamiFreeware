# 자미명반Freeware

누구나 사용할 수 있도록 만들어진 **자미명반Freeware v1.1.1** 입니다.

* 오프라인 사용 가능 (인터넷 연결 불필요)
* 어떠한 개인정보도 수집 및 전송하지 않습니다.


아래 Download 버튼을 누르면 설치파일이 다운로드 됩니다


[![Download](https://img.shields.io/badge/Download-v1.1.1_Setup-blue?style=for-the-badge&logo=windows)](https://github.com/donaldu12/JamiFreeware/releases/download/1.1.1/Freeware.1.1.1Setup.exe)
[![Release](https://img.shields.io/badge/Release_Notes-v1.1.1-green?style=for-the-badge)](https://github.com/donaldu12/JamiFreeware/releases/tag/1.1.1)

> **설치 안내**: 설치파일 실행 시 `C:\자미명반freeware` 경로에 설치됩니다.

# 🚀 실행방법 안내
<br>
* 실행방법 1 - 바탕화면 바로가기 아이콘으로 실행<br>
* 바탕화면에 아래와 같은 [자미명반Freeware]아이콘을 더블클릭해서 실행합니다.
<br>
<img width="112" height="102" alt="image" src="https://github.com/user-attachments/assets/0d68cebd-f36b-4fd7-a49a-beb5544c45a4" />

<br><br>

* 실행방법 2 - 직접 파일 위치에서 실행<br>
* 내컴퓨터 -> c: 드라이브 -> 자미명반Freeware 폴더에 있는 [자미두수.exe] 파일을 실행합니다.
